## 处理结果

分支 `fix/problems-round-2`。每一项都有对应的端到端测试（`node scripts/e2e/run.mjs Q`，见 docs/test-plan.md 的 Q 节）。

1. **红绿灯被压扁**：量了截图里的像素，浅色主题和 Night 下按钮其实都是 28×28、逐像素相同，并没有变形；区别在于按钮上下边缘是一圈亮色描边，在白底上几乎看不见，看起来就扁了。这种没有深色外圈、带亮边的画法是 macOS 深色外观下的样式（本机浅色外观下按钮带深色外圈，在白底上是圆的），说明系统处于深色模式、而主题是浅色。现在窗口的原生外观（红绿灯、菜单、对话框）跟随主题而不是系统：浅色主题用浅色外观，Night 和声明了 `color-scheme: dark` 的自定义主题用深色外观。本机是浅色模式，没法复现截图里的样式，请在深色模式下再看一次。
2. **偏好设置加图标**：通用 / 编辑器 / 图像 / 导出 / 外观前各加了一个 16px 的单色线条图标，颜色跟随文字（深色主题下自动变浅）。
3. **拖拽修改图片大小**：点击选中图片后右下角出现手柄，拖动即可缩放（高度按比例），拖动时显示尺寸；双击手柄恢复原始大小，`⌘Z` 可撤销。Markdown 没有图片尺寸语法，调整过的图片保存为 `<img src="…" alt="…" width="…" />`，重新打开后仍是可点击、可编辑、可再次缩放的图片；Typora 写的 `<img … style="zoom:50%;" />` 也按图片打开。
4. **图片居左 / 居中 / 居右**：偏好设置 › 图像 › 图片对齐，默认居中。作用于单独成段的图片（夹在文字中的图片随文字排列），导出的 HTML / PDF 与编辑器一致；居右时缩放手柄在左下角。
5. **自定义主题与内置主题同时打勾**：原来主题菜单用的是单选项，分隔线把内置主题和自定义主题分成了两组，每组各保留一个选中项。现在改为由编辑器同步的勾选项，任何时候只有当前主题打勾。
6. **PicGo 端口可配置**：偏好设置 › 图像 › 上传服务选 PicGo (app) 时显示“端口”，默认 36677；非法端口会恢复原值，清空则恢复默认。连接失败的提示里会带上端口。
7. **无法通过删除 `*` 取消加粗**：原来显示出来的 `**` 只是装饰，光标只能停在文字一侧。现在光标可以移到标记外侧（点击标记的外半边或行尾，或在文字末尾按 →、在文字开头按 ←），退格 / Delete 会删掉一个标记字符，和 Typora 一样整段变回源码文字（`**1**` → `**1*`），可以继续删；补回 `*` 又会恢复加粗。斜体、行内代码、删除线、链接同样适用。光标在闭合标记外侧时输入的文字不再加粗（包括输入法输入）。

另外修了一处测试时发现的问题：点击“验证图片上传选项”后焦点会离开设置窗口，之后按 Esc 关不掉设置。
