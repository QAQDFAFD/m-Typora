## 处理结果

分支 `fix/problems-list`。每一项都有对应的端到端测试（`node scripts/e2e/run.mjs P`，见 docs/test-plan.md 的 P 节）。

1. **红绿灯被压扁**：在本机（macOS 26.5）没能复现；各主题、打开文件、已编辑、侧边栏打开时截图都正常。改为使用系统默认的红绿灯位置，不再通过 `trafficLightPosition` 自定义坐标——自定义坐标会由 Electron 另建按钮容器，在部分系统/显示器上会裁掉按钮下沿，浅色背景下尤其明显。如果仍能看到，请附一张截图。
2. **侧边栏遮挡文字**：窗口窄于 760px 时侧边栏原本浮在正文上方。现在始终与正文并排，宽度自动收窄，正文至少保留 360px。
3. **搜索漏结果**：原来逐行匹配 Markdown 源码，并在 300 条结果后停止。现在按显示的文字匹配（忽略粗体、链接、行内代码等标记），同一段落里跨行的短语也能找到，空格分隔的多个关键字需全部出现（顺序不限），文件名也参与匹配，每个文件最多 20 条结果，不会再因为前面的文件结果太多而漏掉后面的文件。
4. **文档图标与大纲图标太像**：文档列表改为“叠放的页面”图标，大纲保持不变。
5. **标题不在右侧区域居中**：标题栏按侧边栏宽度偏移，打开、关闭、拖动调整宽度时都保持在正文区域中间。
6. **自定义图床（PicGo）**：偏好设置 › 图像：插入图片时可选“无特殊操作 / 复制到 ./assets / 上传图片”；上传服务支持 PicGo (app)（本地 36677 端口）、PicGo-Core 命令行和自定义命令；“验证图片上传选项”会上传一张测试图片；新增“格式 › 上传全部本地图片”。上传失败时提示并改为保存在本地。
7. **删除标题要按多次**：标题开头按一次退格即变为正文。
8. **文件树箭头太小**：改为 11px 的矢量箭头，点击区域 16px，展开时旋转。
9. **导出 PDF**：原来直接打印编辑窗口，公式块会以源码出现。现在与 HTML 导出共用同一份渲染结果（当前主题、公式、图表、代码高亮），在后台窗口打印；偏好设置 › 导出 可设置纸张大小、页边距和导出后的操作。
10. **设置弹窗**：改为左侧分组（通用 / 编辑器 / 图像 / 导出 / 外观）的两栏布局，可拖动标题移动，关闭后再打开保持位置。
11. **自定义主题**：把 `.css` 放进主题文件夹（「主题 › 打开主题文件夹」或 偏好设置 › 外观），重启后即可在「主题」菜单和偏好设置中选择。自定义主题叠加在 Github 主题之上，只需写要改的部分；文件夹里的 README 有示例和变量说明。
12. **图片网址不换行、不能部分选中**：网址编辑框改为自动换行、随内容增高的多行框；选中图片时页面选区和可拖动状态会让按下鼠标变成“拖动图片”，现在点进编辑框时会先撤掉，可以拖选网址中的一部分。加载失败的图片也会显示可点击的占位框。
13. **导出 HTML**：原来只导出语义 HTML 和固定的 Github 样式，高亮、上下标、表情、Callout、目录、HTML、图表、公式都以源码出现。现在导出的页面与编辑器中看到的一致，带当前主题样式和正文字体；本地图片按 HTML 文件的位置相对引用，或在偏好设置中选择内嵌。“HTML (without styles)” 仍导出纯语义 HTML。
