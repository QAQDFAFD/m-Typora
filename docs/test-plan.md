# m-typora 测试清单

自动化执行：`npm run test:e2e`（构建后启动一个独立的 m-typora 实例，使用临时配置目录和临时文档，通过真实的鼠标 / 键盘事件操作窗口；系统对话框、右键菜单、Finder / 浏览器调用被替换为可检查的桩）。
标记 **手动** 的条目需要人工验证（真正的系统对话框、打印、全屏、其他平台）。

## A. 文件与窗口
| ID | 步骤 | 预期 |
|---|---|---|

| A4 | 文件 › 新建 | 空白“未命名”文档 |

| A6 | 修改后 ⌘S | 写入磁盘，“已编辑”标记消失 |
| A7 | 未命名文档保存 | 弹出另存为，写入所选路径，标题变为新文件名 |
| A8 | 文件 › 重命名 | 标题栏可编辑，回车后磁盘上的文件被重命名 |
| A9 | 在访达中显示 | 调用系统“在访达中显示” |

| A12 | 导出 PDF | 生成非空 PDF |
| A13 | 打开自动保存后编辑 | 约 1 秒后自动写盘 |

| B8 | 输入 `(`、`)`、退格 | 自动配对、跳过右括号、成对删除 |
| B9 | 列表中回车、空项回车、Tab | 续项、退出列表、缩进 |
| B10 | 点击任务复选框 | 切换勾选 |
